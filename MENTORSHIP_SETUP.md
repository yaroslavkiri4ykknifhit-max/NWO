# Mentorship checkout

`/mentorship/buy/` is a static frontend. `mentorship-apps-script.js` runs in a **separate** Google Apps Script project; do not overwrite the course API in `google-apps-script.js` or any COLDDEV project.

## Activation

1. Create an Apps Script project, paste `mentorship-apps-script.js` into Code.gs and run `setupMentorship` once. Authorize spreadsheet creation, mail sending, external rate requests and scheduled retries. The setup creates a private spreadsheet and two triggers. It does not send a payment or mark anyone paid.
2. Set Script Properties listed below. Keep receiving details out of GitHub and frontend bundles. The API returns them only for a registered application with its private access token.
3. Deploy a web app executed as the owner, accessible to Anyone. The web app exposes only the four checkout actions, not arbitrary spreadsheet operations. Never share the underlying spreadsheet publicly.
4. Set the public deployment `/exec` URL in `MENTORSHIP_API_URL` in `lib/mentorship.ts`, or supply `NEXT_PUBLIC_MENTORSHIP_API_URL` at build time. The public endpoint is not an authentication secret. Rebuild GitHub Pages after changing it.
5. Verify a clearly labelled software test application and JPG/PNG/PDF attachment reach the configured owner email. Do not use a real payment, real customer data or automatically accept a real service contract in tests.

## Operation

- `Orders` stores order ID, idempotency key and JSON containing application, consent, immutable legal text, price and receipt/delivery state. Names and other user input are inside JSON, not spreadsheet formulas.
- `ReceiptFiles` stores receipt base64 in chunks of at most 40,000 characters. Only the owner spreadsheet and the recipient email receive the receipt; the public API never returns it.
- No code grants course access or treats a screenshot as confirmed funds. Check the actual bank or wallet balance, then contact the applicant. Issue the document required by the provider's applicable tax rules separately.
- Receipt email is sent as an attachment using **send-only MailApp**. There is no permission to read the owner's mailbox and no public Drive receipt link.
- Pending mail (e.g. exhausted mail quota) is retried every five minutes. A `sending`/`review_required` state needs owner inspection: delivery may have happened before interruption, so it is not automatically resent. After checking the recipient mailbox, the owner can set the relevant `notification` field in the private order JSON to `sent` (and receipt order status to `receipt_received`) or `pending` to retry. Do not change to `paid` on receipt alone.
- Orders without receipt are purged after 30 days. Receipt/application retention, received email copies and mandatory accounting records must be reviewed and removed by the owner when their legal retention period ends. Do not mark customer records paid automatically.
- Signed quote is valid for 30 minutes while completing the application. Registered order locks its amount for 48 hours. NBRB rate must be for the current Minsk date; a stale/unavailable rate stops the checkout rather than inventing a price.
- Receipt accepts JPEG, PNG or PDF up to 5 MiB with signature validation. SVG, HTML and mismatched MIME are rejected. One attachment per application; replacement requires contacting the provider.
- Public API has consent validation, signed quote/token authorization, per-email and daily quotas, application idempotency, receipt digest deduplication and a honeypot. Monitor quotas and abuse; this is a small-volume manual checkout, not an acquiring or blockchain settlement service.

## Updates

Update the existing web-app deployment with a new version to keep the same URL. Update `MENTORSHIP_VERSION` whenever terms change. Existing applications retain the accepted text. The supplied offer is a working draft for this service; it does not constitute a legal review or guarantee that a particular payment method is allowed for the provider.

Checks: `node --test scripts/tests/mentorship-checkout.test.cjs`, `pnpm exec tsc --noEmit`, `pnpm build`.
